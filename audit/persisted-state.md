# What is saved, where, and in which state

[Back to the summary](README.md)

Every file the software writes or reads, consolidated from the readers' tables (the full,
unmerged tables are at the bottom). "Raw" means the decode of the scanner's bytes with no
correction; "corrected" means flat-fielded (and possibly oriented, mono-converted,
downscaled). All paths are **relative to the current working directory** unless given on
the command line: started from another directory, the window and the tools silently begin
a new `library/`, `rolls/` and `calibration/` there.

## Library (`library/`, or `--library`, or `$RPS7200_DEBUG_ROOT` for debug filing)

| File | Format | State | Writer | Reader | Atomic? | Checksum? |
|---|---|---|---|---|---|---|
| `<id>/raw.bin.gz` | gzip 6 of READ payloads (tag + line, LE) | exact bytes (P02, P07, P08 for when absent or wrong) | `library.save` | `read_raw`, `decode_raw`, `reconstruct`, `verify`, demo, `uniformity`, analysis tools | no | sha256 + length |
| `<id>/scan.tif` | TIFF uint16/uint8, C=3/4, lossless | raw -- **except** window Scan and demo (corrected, P01/P26) and 7200 dpi (realigned, P06) | `library.save`; rewritten in place by `migrate-raw`, `migrate-direction` | `load`, `corrected`, GUI full-res/Save As/Export, demo fallback, analysis | no | sha256 |
| `<id>/shading.npz` | npz, float64 per column per channel | derived reference | `library.save` | `load`, `corrected` | no | **none** |
| `<id>/ccd_mask.bin` | bytes | exact | `library.save` | `corrected` | no | **none** |
| `<id>/prescan.tif` | TIFF uint8 | **corrected**, unlabelled | `library.save` (roll frames) | GUI reopen, `scan_roll --approved`, demo | no | **none**, not verified |
| `<id>/scan.json` | JSON, whitelisted meta | -- | `library.save` (last) | everything | no | -- |
| `index.json` | JSON summary | derived | `library.save`, `reindex` | `list` | no | -- |
| (debug spool) `$TMP/rps7200-debug-*/NNN-image.npy`, `NNN-raw.bin` | npy / bytes | raw pixels / bytes | `_debug_capture` | `_debug_flush` after `close()` | -- | -- ; meta only in RAM (P03) |

## Rolls (`rolls/<name>/`, `--rolls`)

`<name>` is the roll field, or **today's date** when it is empty. That is shared by every
unnamed roll of the day ([P18](problems/P18-roll-folder-identity.md)).

| File | Format | State | Writer | Reader | Atomic? |
|---|---|---|---|---|---|
| `survey.json` | JSON manifest of a dry-run walk | -- | session `_roll` / `scan_roll.py`, per frame, **replaced wholesale** by any later walk | GUI reopen, `scan_roll --approved` | no (P19) |
| `roll.json` | JSON manifest of a real roll | frame marked done **before** it is filed | session `_roll` (merged), `scan_roll.py` (**overwritten**, even with `--start-at`) | GUI reopen, resume | no (P19) |
| `approved.json` | JSON: sheet decisions (offset **in mm**, rotation, flip) | -- | GUI `_write_approved`, to `rolls/_safe(name)` = `rolls/roll/` when empty: **a different folder** | session roll, reopen | no; replaced per commission (P19) |
| `prescanNN.tif`, `prescanNN-before.tif` | TIFF uint8 | corrected, oriented by the rotation **at write time** (P20) | FrameWriter / `scan_roll.py` | reopen, `--approved`, sheet | no |
| `frameNN.tif` | TIFF uint16 (or mono) | corrected, oriented | FrameWriter | operator | no; overwritten on rescan |

## Calibration cache

| File | Format | State | Writer | Reader | Atomic? |
|---|---|---|---|---|---|
| `calibration/shading.npz` | npz ShadingReference | derived; no mask, no provenance, no age in the entry | `ensure_shading` -> `save_shading` on every measured calibration | `--reuse`, GUI "Use the cached one" | no; a failed write discards the calibration (P05) |

## Delivered files (operator's copies)

| File | State | Writer | Notes |
|---|---|---|---|
| `<out>/...tif` / `.jpg` (+ `.dng` sidecar) | corrected, oriented, optional mono | FrameWriter (per scan), Save As, Save all, Export rolls | Written **before** the library entry (P04). Save As, Save all and Export pass no dpi (TIFF says 72). `_unclaimed` names are picked on one thread and written on another (race). A JPEG export can overwrite an existing `.dng` |
| `tools/scan.py --out` (default `./scan.tif`) + `<out>.json` | merged, corrected | `scan.py` | Overwritten without asking; not in the library |
| `1_nothing_done.tif`, `2_corrected.tif`, `3_corrected_inverted.tif`, `previews/cmp_*.png` | from an arbitrary TIFF, **destripe** not shading | `make_comparison.py` | Do not show the shipped correction (P30) |

## Window state

| File | Format | Writer | Notes |
|---|---|---|---|
| `gui-settings.json` (or `$RPS7200_SETTINGS`, `demo/gui-settings.json`) | JSON: controls, film, output folder, presets, shortcuts, rolls, **sheet decisions** | `settings.save` (atomic: `.part` + replace) | A corrupt file is discarded **silently** and overwritten. A failed save is silent. Two windows share it |

## Demo

| File | Writer | Notes |
|---|---|---|
| `demo/library/...` | the unchanged session path | corrected-as-raw, with the **source** entry's bytes and reference; no demo marker (P26) |
| `demo/rolls/...`, `demo/gui-settings.json` | as the real paths | `--library` / `--rolls` / `--out` override these **without** protection. A demo run can write into real folders |
| `demo/pictures.npz` | demo-pictures thread | signatures of source pictures; truncated if the window closes during the first launch |

## What is *never* saved anywhere

- calibration bytes, calibration info block, calibration mask, gain/offset read-backs (P05)
- metering probe passes (outside ad-hoc debug scripts), hold / aim / verification
  prescans, the pre-correction prescan, CLI walk prescans' bytes (P08)
- the INQUIRY; MODE SELECT byte 14, `slide_init_param`, GET PARAMETERS response, sense
  data; the SLIDE bytes that placed a frame; detector members' answers (P09)
- bracket membership and ratios, the merged bracket result; metering for roll frames (P09, P29)
- the session log: failed filings and dropped raw bytes are reported only in a log widget
  (P24)
